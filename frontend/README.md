# Frontend (Didulana, Hareen)

```bash
npm create vite@latest . -- --template react
npm install
npm install recharts
npm run dev        # http://localhost:5173
```
API base URL: `http://localhost:8000` (set `VITE_API_URL`). Contract: `../docs/API.md`.
Pages: Check a message · Monitoring (drift signals + charts + alerts) · Review queue (+ Retrain button).
